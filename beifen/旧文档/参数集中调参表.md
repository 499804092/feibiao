> **用途**：把所有可调参数汇总到一个文件，测试时只改这里、对照这里。
>
> **两个工程分开标注**：
> - 🅰️ **`feibiao/`（本文件夹）** = `2024_Dart_Algorithm` 视觉端（PC/Ubuntu + OpenVINO 模型）
> - 🅱️ **`feibiaodaima/feibiao/`** = MaixCAM 板端有控飞镖工程（板载直接识别+制导）

| 参数 | 当前值 | 含义 | 怎么调 |

| `uvc.width` | `640` | 采集宽度 | **别用 1080P**，网络输入是 640×384，缩放倍率差太多会掉精度 |

## A2. 检测参数 —— `Vision_Code/config/json/detect.json`

| 参数 | 当前值 | 含义 | 怎么调 |
|---|---|---|---|
| `path.xml` / `path.bin` | `../config/openvino/Katrin.*` | 模型路径 | 换模型时改 |
| `path.device` | `CPU` | 推理设备 | `CPU` / `GPU` / `AUTO`。**这台虚拟机无独显，用 CPU** |
| `openvino.width` / `height` | `640` / `384` | 网络输入尺寸 | **与模型绑死，不要改** |
| **`min_objectness`** | **`0.20`** | objectness 粗筛阈值 | ⬇️ 调低=更容易检出（远/暗目标用 0.15）；⬆️ 调高=压误检 |
| **`class_threshold`** | **`0.50`** | 类别得分阈值 | 实测绿光类别得分 1.00，很安全。误检多就升到 0.7 |
| `nms_threshold` | `0.25` | NMS 的 IoU 阈值 | 同目标出多框就调小（0.2）；漏检就调大（0.4） |
| `score_threshold` | `0.25` | 旧参数（保留兼容） | 已被上面两个替代，可忽略 |

### 实测参考值（调阈值时对照）

| 场景 | 类别得分 | objectness |
|---|---|---|
| 引导灯**照片**（清晰、近距离） | 0.998 | **0.84** |
| **实时相机**（有运动模糊） | 1.00 | **0.25 ~ 0.48** |

> **关键**：objectness 实时只有 0.25~0.48，所以原本 0.5 的阈值会导致真机一帧都检测不到。这是把阈值降到 0.20 的原因。

## A3. 解算参数 —— `Vision_Code/config/json/track.json`

### 相机内参（★ 未标定，当前不准）

| 参数 | 当前值 | 应该是 | 说明 |
|---|---|---|---|
| `camera.fx` | `1706.0` | **待标定** | 水平焦距(像素)。来源：`sensors.json` 的棋盘格标定 `1.7060e+03` |
| `camera.fy` | `1705.1` | **待标定** | 垂直焦距(像素)，来源同上 `1.7051e+03` |
| `camera.cx` | `320.0` | `320` ✅ | 光心 x = 640/2，正确 |
| `camera.cy` | `320.0` | ⚠️ **应为 `240`** | 光心 y = 480/2。当前 320 来自 640×640 的标定，**会导致 pitch 有约 2.7° 固定偏差** |

**没标定会怎样**：
- `yaw` 的**零点是对的**（cx 准确）→ 相对偏差可用，飞控能闭环
- `pitch` 的**零点偏了约 2.7°** → 有固定俯仰偏差
- 角度**绝对数值**的缩放取决于 fx 准不准
- `distance` 的**绝对精度**同时依赖 fx 和 target 尺寸，会错

**临时改善**：把 `cy` 改成 `240`（480/2），pitch 零点就正了。

**正式标定方法**（有棋盘格时）：
```bash
python3 -c "
import cv2, glob, numpy as np
objp = np.zeros((6*9,3), np.float32); objp[:,:2] = np.mgrid[0:9,0:6].T.reshape(-1,2)
obj, img = [], []
for f in glob.glob('calib/*.jpg'):
    g = cv2.cvtColor(cv2.imread(f), cv2.COLOR_BGR2GRAY)
    ok, c = cv2.findChessboardCorners(g, (9,6), None)
    if ok: obj.append(objp); img.append(c)
r, K, d, _, _ = cv2.calibrateCamera(obj, img, g.shape[::-1], None, None)
print('fx=%.1f fy=%.1f cx=%.1f cy=%.1f' % (K[0,0], K[1,1], K[0,2], K[1,2]))
"
```

### 目标尺寸（★ 决定测距精度）

| 参数 | 当前值 | 说明 |
|---|---|---|
| `target.width_m` | `0.15` | ⚠️ **占位值，必须实测标定** |
| `target.height_m` | `0.15` | 同上 |

**标定方法**：靶放已知距离 `Z0`（如 2.00m），用 `uvc_detect_view` 量出检测框宽 `w0` 像素，则
```
target.width_m = Z0 × w0 / fx
```

# 调参建议顺序

## 🅰️ 视觉端（`feibiao/`）

1. **先定朝向** `uvc.orientation` → 跑 `./uvc_orient`，对着靶子看哪个正
2. **再定阈值** `min_objectness` → 跑 `./uvc_detect_view --thr 0.20`，看能不能稳定框住
3. **标定内参** `camera.fx/fy/cx/cy` → 有棋盘格就跑标定；没有就先把 `cy` 改成 `240`
4. **标定目标尺寸** `target.width_m` → 已知距离反算
5. **调滤波** `euro.*` → 目标抖就降 `min_cut_off`，跟不上就升 `beta`
6. **调时间常数** `selection.*` → 误锁就升 `min_found_frame`，反应慢就降

## 🅱️ 板端（`feibiaodaima/feibiao/`）

1. **确认 IMU 方向**：静止看 `Angle[0..2]` 和 `w[0..2]` 符号对不对
2. **确认舵机中立**：静止时四舵机应在 `g_servoX_neutral` 附近
3. **小步调 `g_k_p`**：从 3.0 开始，先降后升，每次记录
4. **调俯仰 PID**：先 `pid_Kp_angle`，再加 `pid_Kp_gyro` 阻尼
5. **加补偿**：`g_pitch/yaw/roll_compen` 抵消常值偏差

> ⚠️ **改参数一定要小步、记录、可回退**。以上所有值都是参考起点，实际以台架/外场实测为准。
